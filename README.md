# THE MCU ARCHIVE
 *A watchlist across time.*
 ![MCU Watchlist](/images/mcu-ss.png)

 
## Purpose
Created for fans who want to seamlessly navigate and track their journey through the Marvel Cinematic Universe. It combines a clean, timeline-focused watchlist with a high-end, responsive design—making the entire MCU viewing experience intuitive and visually engaging across all devices.

## Design & Craft
- Concept, visual layout, responsive architecture, and fine details designed by me.
- Built with the assistance of **GitHub Copilot** and **Gemini** to streamline implementation and refine interactive features.
